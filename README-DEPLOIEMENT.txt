RÉUSSITE FACILE — MISE À JOUR DU SITE

CONTENU DU PACK
- index.html : page d'accueil et première zone de cours
- style.css : mise en forme responsive
- script.js : leçons et quiz de démonstration
- a-propos.html, contact.html, confidentialite.html : pages d'information à compléter

IMPORTANT
Les leçons sont des exemples pédagogiques de démarrage, pas un programme officiel exhaustif.
Vérifie les progressions et les notions avec les documents du ministère ivoirien et les enseignants.
Remplace l'adresse e-mail fictive/à compléter par une adresse que tu consultes réellement.
La politique de confidentialité doit être adaptée à tous les outils réellement installés sur le site.

INSTALLATION SUR GITHUB (TÉLÉPHONE)
1. Ouvre ton dépôt GitHub : si1234dikouattara-source / reussite-facile.
2. Appuie sur Add file / Ajouter un fichier, puis Upload files / Importer des fichiers.
3. Décompresse ce ZIP sur ton téléphone avant l'envoi. Envoie les fichiers eux-mêmes (index.html, style.css, script.js, a-propos.html, contact.html, confidentialite.html), pas le dossier ZIP.
4. Si GitHub demande de remplacer les fichiers existants, vérifie que tu es dans le bon dépôt puis confirme.
5. Descends à Commit changes / Valider les modifications. Message : Mise à jour du site et ajout des premiers cours.
6. Attends le déploiement GitHub Pages, puis ouvre :
https://si1234dikouattara-source.github.io/reussite-facile/

Le fichier index.html doit rester à la racine du dépôt, pas dans un sous-dossier.
