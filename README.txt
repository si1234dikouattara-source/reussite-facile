RÉUSSITE FACILE — SITE ÉDUCATIF DE DÉPART

Contenu :
- index.html : page d'accueil et mini-quiz interactif
- style.css : mise en page responsive
- script.js : fonctionnement du quiz et du menu
- a-propos.html, contact.html, confidentialite.html : pages de base

AVANT PUBLICATION :
1. Remplace le nom "Réussite Facile" si tu veux une autre marque.
2. Remplace l'adresse e-mail d'exemple dans contact.html par une adresse réelle.
3. Vérifie et enrichis les cours, exercices et réponses. Le contenu actuel est une démonstration courte, pas un site éducatif complet.
4. Adapte la politique de confidentialité à tes outils réels et à tes obligations légales.
5. N'ajoute le code AdSense officiel qu'après l'avoir obtenu dans ton compte.
6. Ne clique jamais sur tes propres annonces et ne demande pas à d'autres de cliquer.

MISE EN LIGNE :
- Téléverse tous les fichiers en conservant la même structure dans le dossier public de ton hébergeur (souvent public_html).
- La page d'accueil doit être nommée index.html.
- Active HTTPS/SSL chez ton hébergeur.
- Teste le site sur téléphone et ordinateur.
